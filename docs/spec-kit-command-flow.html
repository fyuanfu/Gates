Convergence 闭环
gap?
→
YES：append tasks.md  →  implement  →  converge  →  重复直到收敛
gap?
→
NO：Done / Review / PR
核心逻辑：前半段完成 Intent 与 Artifact 的逐层展开，analyze 在实现前检查跨文档一致性和覆盖， implement 执行任务，converge 再把当前代码与 Spec / Plan / Tasks 对齐， 对未完成项追加新的任务，从而形成实现闭环。
