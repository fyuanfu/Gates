# Scope

本迭代支持用户为一条待办事项切换完成状态。

# Requirements

- RQ-TODO-01：已登录用户点击未完成待办的复选框后，服务端保存 `completed=true`；服务端确认保存后，该待办显示为已完成。点击已完成待办的复选框时按同样规则保存 `completed=false` 并显示为未完成。
- RQ-TODO-02：保存失败时保持点击前状态、显示“保存失败”，并允许用户再次点击。
- AC-TODO-01：构造保存成功响应，分别验证未完成到完成、完成到未完成；界面状态与服务端返回值一致。
- AC-TODO-02：构造保存失败响应，验证状态不变、显示失败提示且可以再次点击。
