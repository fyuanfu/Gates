04 / 读懂矩阵的三个重要结论

对手机厂商和供应链企业都适用
INSIGHT 01

品牌拥有产品定义权，不等于亲自制造

OPPO 对品牌定位、上市决策、关键体验和质量准入负责，同时可能委外 SMT、PCBA、整机制造。其 Noida 自有工厂与 Bhagwati 部分外包生产是能够同时成立的事实。

INSIGHT 02

ODM 负责的可以是“研发 + 量产”

华勤、龙旗具备设计与制造服务能力，但公开确认合作关系不代表所有设计任务都已转移。应逐项目查清原理图、BSP、整机测试、供应链采购与缺陷责任等合同边界。

INSIGHT 03

质量责任必须区分执行和批准

外部工厂可执行 DVT、PVT、EOL 或 OQC，品牌仍需对验收标准、重大质量风险、量产及市场放行进行治理。第三方认证也只覆盖指定的标准与指标。

05 / 如何理解证据

避免供应链图中最常见的事实混淆

证据等级

具体机型：证实某型号采用某器件或认证。
品牌官方 / 已公开合作：证实品牌能力或厂商合作关系，但不自动落到单款机型。
行业研究：独立机构跟踪到的制造关系。
行业推演 / 未核实：只用于刻画产业链惯例，不视作事实性供货名单。

职责范围和词语定义

品牌 OEM：OPPO 作为产品拥有方；ODM：承接设计和制造的合作方；EMS：电子制造服务，主要承接制造、工艺与生产测试。
EVT / DVT / PVT：工程、设计、生产验证的行业通用阶段名。
SMT / PCBA：SMT 是贴装工艺；PCBA 是组装后的电路板或其装配加工活动。
